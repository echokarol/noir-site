# NOIR

Статический адаптивный сайт барбершопа на HTML, CSS и JavaScript. Сборка, установка пакетов, API-ключи и backend не нужны.

## Файлы

- `index.html` — главная страница, разделы, галерея и форма демонстрационной записи.
- `styles.css` — дизайн, адаптивная вёрстка и модальные окна.
- `script.js` — мобильное меню, просмотр фотографий, проверка формы.
- `assets/images/` — локальные фотографии: `interior.jpg`, `barber.jpg`, `tools.jpg`.
- `scripts/serve.cjs` — вспомогательный HTTP-сервер только для локального просмотра. Ничего не принимает и не сохраняет.

Все ресурсы подключаются относительными путями. Сайт можно размещать в корне домена или в подпапке. Шрифты системные, внешних библиотек нет.

## Локальный запуск

Нужен установленный Node.js 18 или новее. Откройте терминал в папке с `index.html` и выполните:

```sh
node scripts/serve.cjs
```

Откройте http://127.0.0.1:8080 в браузере. Для остановки нажмите Ctrl+C в терминале. Если порт занят, в PowerShell выберите другой:

```powershell
$env:PORT = '8081'
node scripts/serve.cjs
```

Сервер доступен только с этого компьютера. Для простого просмотра можно открыть `index.html` двойным щелчком, но проверять публикацию лучше через HTTP.

## Публикация

Подойдёт любой хостинг статических файлов. Платные сервисы не подключены.

1. Загрузите `index.html`, `styles.css`, `script.js` и всю папку `assets` в каталог публикации, сохранив имена и структуру.
2. Если хостинг спрашивает команду сборки, оставьте её пустой: сборка не требуется. Каталог публикации — каталог, содержащий `index.html`.
3. Не запускайте `scripts/serve.cjs` на хостинге: он нужен только для локального просмотра. README и папку `scripts` можно не публиковать.
4. Откройте адрес сайта и проверьте меню, фотографии и форму. При обновлении замените изменённые файлы и обновите страницу с очисткой кеша.

Сайт подготовлен к загрузке, но автоматически не опубликован.

## Демонстрационная запись

Кнопка «Записаться» и строки услуг открывают форму. Все четыре поля обязательны. Имя не может состоять из пробелов; телефон должен содержать 10–15 цифр (допустимы +, пробелы, скобки и дефисы). Услуга и время выбираются из списка.

Успех показывается исключительно в браузере. Сетевой отправки, cookies, localStorage, базы данных и настоящего бронирования нет. Поля очищаются после демонстрационной отправки и при закрытии окна. Управление автозаполнением самого браузера остаётся на его стороне.

Цены, время работы и фотографии иллюстрируют концепцию; адрес и контакты пока не указаны. Перед реальным открытием обновите эти сведения.
